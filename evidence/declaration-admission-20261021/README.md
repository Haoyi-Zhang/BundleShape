all 30 pass normally and under Python optimization. The public unit command
also passes its unchanged 108-method domain, without failures, errors or skips.

literal data and equivalent chunk-boundary behavior. Public commands issue and
replay admission witnesses and reject positive witnesses for excluded inputs.

method names and raw stdout/stderr. Each `*-summary.json` is a byte-for-byte copy
of that command's real output, including its measured local wall time.

`environment.json` records the actual CPython 3.12.14 Windows environment.
Literal host staging/output paths in the raw commands are provenance, not
directories included in this artifact; use a fresh output path when replaying.
Temporary owned fixtures are not shipped here.

stage of `reproduce.py` discover the added declaration module without an
explicit test-name list. The local CI-equivalent discovery is separately recorded
in the private verification report; no remote CI run is claimed.

supplemental receipts, remains byte-identical. Frozen finite experiments,
